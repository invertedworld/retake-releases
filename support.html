Retake — Support

The manual

Retake includes its user manual: choose Help › User Manual (PDF). Contextual help is on by default — pause the pointer over any control for a description — and Help › Keyboard Shortcuts lists the shortcuts.

Common questions

Retake can't record the screen. It needs Screen Recording access: System Settings › Privacy & Security › Screen & System Audio Recording, and turn Retake on. If the switch is on but recording still fails, remove Retake from the list with the – button, add it again, and reopen Retake.

Computer sound is missing from a recording. Turn on Computer sound in the Preflight Check before recording. Sound from a single app is recorded only when that app's window is the source.

Keystrokes don't appear. The keystroke overlay needs Input Monitoring: System Settings › Privacy & Security › Input Monitoring. It is optional; the Keystrokes switch in the Preflight Check turns it on and off.

The Export sheet says the project uses Full Version features. That is the free version: pointer path editing, automatic zooms, 3D rotation, the keystroke overlay, captions drawn in the video, camera background removal and 4K/HEVC export can be used and previewed, but a project that uses them is exported once the Full Version is unlocked. Turn them off, or choose Retake › Unlock Full Version… (Mac App Store) or enter your licence under Retake › License… (download from this site). On the App Store, Restore Purchases brings a purchase to another Mac signed in to the same Apple Account.

Where are my projects? In Movies › Retake unless you chose another place. A project is a folder ending in .retake with the recordings inside; keep the folder together.
